PADRÃO ECOCIENTE

Criador de Repositórios

Crie um novo repositório já preparado com o template oficial do EcoCiente.

Para criar repositórios, entre com sua conta do GitHub. Apenas membros ativos da organização EcoCiente-Instituto-J-F podem usar esta ferramenta.

Recomendamos seguir o padrão <matéria>-<nome-do-repositório>.

Essa descrição aparecerá na página do repositório. 0/350

Visibilidade
Atenção: a ferramenta tentará aplicar a proteção da branch main , mas a disponibilidade em repositórios privados depende do plano e das políticas da organização. Se o GitHub não permitir, o repositório será criado normalmente e você receberá um aviso. Em caso de dúvida, contate o Mestre DevOps Julio .
